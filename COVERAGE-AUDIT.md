counts what ESPN *returns*, competition by competition, so a slug that
is wired up everywhere but answers nothing can no longer hide.

Window: fixtures within ±7 days of the run.

| Verdict | Meaning |
|---|---|
| 🔴 in play | A match was actually in progress when the audit ran |
| 🟢 active | ESPN has fixtures for this league dated inside the window |
| 🟣 scheduled | In season with a confirmed next fixture, just none this week (international break, mid-week gap) |
| 🔵 table only | No fixtures at all, but ESPN holds a populated standings table |
| 🟡 idle | ESPN answers, but has nothing scheduled — out of season |
| ⚪ empty | ESPN answered with a payload carrying no league identity |
| ⛔ dead | HTTP error or timeout — the slug should be dropped |

Fixture counts are events **dated inside the window**. ESPN hands back a
league's most recent match even when it is months out of season, so an
event only counts if its own date lands in the window.
