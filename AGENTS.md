# ScoreHub — Base44 Dev Environment

## What this is
A purely static sports-scores website (HTML/CSS/JS). No backend, no build step, no package.json.
Live data comes from public ESPN APIs fetched client-side (`site.api.espn.com`, `site.web.api.espn.com`).
No external credentials are required.

## How it runs
- `docker compose -f docker-compose.base44.yml up -d` starts an `nginx:alpine` container.
- The repo root is bind-mounted read-only at `/app`; nginx serves it on container port 80, mapped to host port 3000.
- `nginx.base44.conf` handles folder-based routing (directories serve `index.html`), CORS headers, and MIME types.
- Edits to HTML/CSS/JS are visible on browser refresh — no rebuild needed.

## Prerendered content
Subdirectories like `table/<league>/`, `report/<matchId>/`, `preview/<matchId>/`, and `<sport>/` contain prerendered
`index.html` files generated by GitHub Actions (`tools/prerender.mjs`, `tools/build-sport-pages.mjs`).
These are committed to the repo and served as-is.

## Verification
- `curl http://localhost:3000/` should return the ScoreHub homepage HTML.
- `curl http://localhost:3000/basketball/` should return the basketball page.
- `curl http://localhost:3000/table/eng.1/` should return the Premier League standings page.
