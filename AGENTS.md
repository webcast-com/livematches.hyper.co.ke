# ScoreHub — Base44 Dev Environment

## What this is
A purely static sports-scores website (HTML/CSS/JS). No backend, no build step, no package.json.
Live data comes from public ESPN APIs fetched client-side (`site.api.espn.com`, `site.web.api.espn.com`).
No external credentials are required.

## How it runs
- `docker compose -f docker-compose.base44.yml up -d` starts an `nginx:alpine` container.
- The repo root is bind-mounted read-only at `/app`; nginx serves it on container port 80, mapped to host port 3000.
- `nginx.base44.conf` handles folder-based routing (directories serve `index.html`), CORS headers, and MIME types.
- Edits to HTML/CSS/JS are visible on browser refresh — no rebuild needed.

## Prerendered content
Subdirectories like `table/<league>/`, `report/<matchId>/`, `preview/<matchId>/`, and `<sport>/` contain prerendered
`index.html` files generated by GitHub Actions (`tools/prerender.mjs`, `tools/build-sport-pages.mjs`).
These are committed to the repo and served as-is.

## Google Analytics (GA4)
- `analytics.js` loads `ga-config.js` first; a valid `G-…` id turns GA4 on and `window.shTrack(name, params)` fires events. The committed `ga-config.js` is an (empty) placeholder for plain static deploys.
- The sandbox serves `/ga-config.js` generated at container start from the `GA_MEASUREMENT_ID` env var (platform env file → `docker-compose.base44.yml` → `nginx.base44.conf`). Unset → empty id → GA disabled, site boots normally.
- Preview builds set `SCOREHUB_PREVIEW=1` (from `BASE44_PREVIEW_MODE`) and are never tracked — GA data stays clean of preview traffic.
- Match-interest events: `match_open` (every entry into a match page — cards, hub rows, ticker, search, spotlight), `match_report_view` (report.html), `match_preview_view` (preview.html). GA's automatic page_view covers the URLs themselves.
- Static snapshot pages (`/report/<id>/`, `/preview/<id>/`, `/table/<league>/`) get an inline GA snippet on the next `tools/prerender.mjs` run when `GA_MEASUREMENT_ID` is in the environment (add it as the GA_MEASUREMENT_ID GitHub secret for the prerender workflow).
- GA4 custom params (match_id, competition, …) must be registered as custom dimensions in the GA4 property before they appear in reports.

## Verification
- `curl http://localhost:3000/` should return the ScoreHub homepage HTML.
- `curl http://localhost:3000/basketball/` should return the basketball page.
- `curl http://localhost:3000/table/eng.1/` should return the Premier League standings page.
